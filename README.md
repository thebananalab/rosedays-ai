# ROSEDAYS.AI — Portfolio 26

Vite + React + GSAP + three.js. The home is a 3D image carousel; each project opens into a framed image/video gallery.

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production build in dist/
npm run media        # re-optimise originals into public/media (needs ffmpeg + the source folder)
```

Content lives in `src/data/projects.js` (site copy, per-project year/tags/blurb) and `src/data/manifest.json` (generated by `npm run media`).

Deploys to GitHub Pages via `.github/workflows/deploy.yml` (base path `/rosedays-ai/`).
